# Hiran Rajbanshi - Portfolio

A responsive cybersecurity portfolio built with HTML, CSS, and JavaScript.

## Files

- `index.html` - portfolio content and project links
- `styles.css` - responsive terminal-inspired design and animations
- `script.js` - accessible cursor-follow glow
- `Hiran_Rajbanshi_IT_Support_Cybersecurity_CV.pdf` - downloadable CV
- `assets/world-map.png` - public-domain world map base by John Harvey via Wikimedia Commons

## Run locally

Open `index.html` in a browser. The profile photo and typefaces load from GitHub and Google Fonts.

## Deploy

Publish from the `main` branch root with GitHub Pages. No build command is required. The same static files can also be hosted by Netlify or Cloudflare Pages.

The animated threat paths are illustrative and do not represent live threat-intelligence data.
